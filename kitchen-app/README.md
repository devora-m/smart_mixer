# צעד בטוח במטבח – אתר ניהול מתכונים

אתר React לניהול מתכונים עבור מערכת המיקסר החכם "צעד בטוח במטבח".  
מתחבר לשרת Node.js קיים עם MongoDB ו-SQLite.

---

## מבנה הפרויקט

```
src/
├── App.jsx                     # קומפוננטה ראשית – ניתוב, מצב גלובלי, טעינת נתונים
├── index.jsx                   # נקודת כניסה – רינדור ל-DOM
│
├── components/
│   ├── Header.jsx              # כותרת עליונה + כפתורי ניווט + הגדרות שרת
│   ├── LoginModal.jsx          # חלון התחברות (סיסמה)
│   ├── FilterBar.jsx           # פס חיפוש וסינון מתכונים
│   ├── RecipeCard.jsx          # כרטיסיית מתכון (ברשימה הראשית)
│   ├── RecipeDetail.jsx        # דף פרטי מתכון מלא
│   ├── RecipeWizard.jsx        # אשף הוספת מתכון (3 שלבים)
│   ├── StepEditor.jsx          # עורך שלב בודד (7 סוגים)
│   ├── StepDisplay.jsx         # תצוגת שלב בודד (פרטים + סקירה)
│   ├── IngredientPicker.jsx    # בורר רכיבים מ-SQLite (dropdown)
│   ├── WhipFields.jsx          # שדות הקצפה (סוג קצף, חומר, מהירות)
│   └── Field.jsx               # עטיפת שדה טופס עם תווית
│
└── utils/
    ├── api.js                  # פונקציות תקשורת עם השרת
    ├── constants.js            # קבועים (קטגוריות, סוגי שלבים, צבעים)
    ├── lookups.js              # חיפוש שמות רכיבים/יחידות/קצף לפי ID
    └── styles.js               # סגנונות משותפים (כפתורים, שדות קלט)
```

## התקנה והפעלה

```bash
# 1. התקנת תלויות
npm install

# 2. הפעלת שרת הפיתוח
npm start
```

האתר ייפתח בכתובת `http://localhost:3000`.  
וודא שהשרת Node.js פועל ב-`http://localhost:4000` (ניתן לשנות דרך הגדרות).

## כניסה

1. לחץ על **כניסה** בכותרת
2. הזן את הסיסמה שהוגדרה בשרת (דרך `npm run set-password`)
3. לאחר הצלחה – יופיע כפתור **+ מתכון חדש**

## הוספת מתכון

האשף מחולק ל-3 שלבים:

### שלב 1 – פרטי המתכון
שם (עברית + אנגלית), קטגוריה, רמת קושי, זמן הכנה, מנות.  
**הקוד נקבע אוטומטית** (הקוד הגבוה ביותר + 1).

### שלב 2 – שלבי הכנה
בחירת סוג שלב ומילוי שדות:
- **ADD** – בחירת רכיבים מ-dropdown (מ-SQLite)
- **MIX** – מהירות (סליידר 1-10) + זמן
- **MIX_ADD** – מהירות → רכיבים → זמן נוסף
- **WHIP** – סוג קצף + חומר + מהירות
- **WHIP_ADD** – הקצפה → רכיבים → זמן נוסף
- **INSTRUCTION** – טקסט חופשי (עד 63 תווים)
- **FINISH** – ללא שדות

### שלב 3 – סקירה ושמירה
סיכום הכל → שמירה לשרת MongoDB.

## Endpoints בשימוש

| Endpoint              | שימוש                        |
|-----------------------|------------------------------|
| GET /api/recipes      | טעינת כל המתכונים            |
| POST /api/recipes     | יצירת מתכון חדש (דורש אימות) |
| GET /api/ingredients  | רכיבים מ-SQLite              |
| GET /api/units        | יחידות מידה מ-SQLite         |
| GET /api/foam-types   | סוגי קצף מ-SQLite            |
| POST /api/auth/verify | אימות סיסמה                  |
